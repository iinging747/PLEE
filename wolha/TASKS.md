## 패널 이미지 에셋 만들기 (Codex)

샷 데이터와 이미지 프롬프트는 25화 모두 채워져 있다. Codex에서 아래를 순서대로 붙여 넣으면 실제 그림으로 패널을 채운다. 작업 목록은 `assets/jobs/`에 있다.

**① 레퍼런스 (한 번만)**
```
wolha/AGENTS.md 의 "이미지 에셋" 절을 읽어.
wolha/assets/jobs/refs.jsonl 에서 kind 가 character 이고 ref 에 "__" 가 없는 줄(14명)을 이미지 생성 도구로 만들어 각 out 경로에 저장해.
prompt 그대로, size 크기, 글자 없이. 다 만들면 14장을 나한테 보여 줘.
```
승인한 뒤:
```
refs.jsonl 에서 ref 에 "__" 가 들어간 변형 시트 8장(정겸 관복·맨상투, 정조 삿갓 변장·행차 복식, 안 내관 변장, 윤희 장옷·혼례복, 정겸 신랑 사모관대)을
각 줄의 refs 에 적힌 기본 시트를 참고 이미지로 붙여서, 같은 얼굴로 만들어. 그다음 location 줄도 같은 방식으로 만들어.
끝나면 cd wolha && python3 tools/compress_frames.py --refs && python3 tools/codex_jobs.py 를 실행하고
"assets: 레퍼런스 시트" 로 커밋·푸시해.
```

**② 패널 (2~3화씩)**
```
wolha/AGENTS.md 의 "이미지 에셋" 절대로 1화와 2화 패널을 만들어.
wolha/assets/jobs/ep01.jsonl, ep02.jsonl 의 한 줄이 샷 하나야. refs 의 그림을 참고 이미지로 붙이고 prompt 로 생성해서 out 경로에 저장해.
얼굴·의상·세트는 레퍼런스와 같게, 그림 안에 글자는 넣지 마.
reuse 가 있는 줄은 그리지 말고 건너뛰어. 회차가 끝날 때마다 compress_frames → codex_jobs --attach → validate → render → board 를 돌리고,
out/epNN.html 에서 설명과 크게 다른 컷은 다시 만든 뒤 "assets: epNN 패널 N장" 으로 커밋·푸시해.
```
회차 번호만 바꿔 가며 25화까지 반복한다. 진행 상황은 `python3 tools/codex_jobs.py --status`.

**20부작·24부작 번호로 이미 만든 그림이 있을 때 (먼저 한 번)**

24부작·25부작으로 늘리기 전에 만든 그림(1,127컷 판 등)은 회차 번호가 다르다. 옛 작업 폴더는 그대로 두고 새 폴더에서 옮긴다.
```
wolha 그림을 25부작 번호로 옮겨 줘. 지금 작업 폴더는 건드리지 말고:
git fetch origin claude/serene-bardeen-piz2m5
git worktree add ../plee24 origin/claude/serene-bardeen-piz2m5
cd ../plee24/wolha
python3 tools/import_frames.py <지금 작업 폴더>/wolha --dry-run 으로 대응표를 확인한 뒤, --dry-run 없이 다시 실행해.
PNG 가 섞여 있으면 회차마다 python3 tools/compress_frames.py N 을 돌리고 python3 tools/codex_jobs.py --attach N 으로 다시 붙여.
python3 tools/validate.py 오류 0, python3 tools/board.py 로 out/board.html 을 다시 만든 뒤
git add assets storyboards && git commit -m "assets: 옛 패널 그림을 25부작 번호로 옮김" && git push origin HEAD:claude/serene-bardeen-piz2m5
그다음부터는 ../plee24 에서 ② 를 이어 가.
```
번호 대응(20부작 → 25부작): 1~7화는 그대로, 8~11 → 9~12, 12~15 → 14~17, 16~18 → 20~22, 19~20 → 24~25. 24부작 번호였다면 18~24 → 19~25. 옛 작업 폴더에 storyboards/ 가 있으면 샷 id 가 아니라 내용(image_prompt·frame)으로 새 샷을 찾아 붙이므로, 회차 중간에 컷이 끼어들어 id 가 밀린 곳(예: 12화 S#5 쇠부채 싸움, 21화 S#5)도 제자리에 들어간다. 비슷한 샷을 못 찾은 그림은 건너뛰고 목록을 보여 준다. 새 회차 8·13·18·19·23화 전체와 새로 끼운 컷은 그림이 없으니 ② 로 만든다.

API 키로 직접 돌릴 때는 `OPENAI_API_KEY=... python3 tools/gen_images.py 5 --run --limit 3`도 쓸 수 있다(레퍼런스 이미지는 붙지 않는다).

## 샷을 다시 짤 때 (대본이 바뀐 경우)

```
wolha/AGENTS.md 와 wolha/docs/storyboard_guide.md 를 먼저 읽어.
견본은 wolha/storyboards/ep01.json 이야.

이번 작업: 대본이 바뀐 wolha/storyboards/ep02.json, ep03.json 의 shots 를 다시 짜 줘.
- 대본은 wolha/shortform/ep02.md, ep03.md. 대사는 원문 그대로, 이야기는 추가하지 마.
- 회차당 샷 30~60개, 씬별 샷 길이 합 = 씬 타임코드 구간, 회차 합계 180초.
- wolha/TASKS.md 진행표의 '꼭 챙길 그림'을 반드시 넣어.
- 끝나면 python3 wolha/tools/validate.py 로 오류·경고 0을 만들고,
  python3 wolha/tools/render.py 2 3 으로 콘티 시트를 만든 뒤 status 를 "review" 로 바꿔.
- 회차마다 따로 커밋하고, TASKS.md 진행표 상태도 갱신해.
```

대본을 고친 회차만 `python3 tools/skeleton.py N --force` 로 뼈대를 다시 만든 뒤 맡긴다.
