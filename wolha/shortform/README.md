# 「월하노인을 잡아라」 숏폼 20부작 대본 (회당 3분)

16부작 원작 대본(회당 60분용)을 회당 3분, 20부작(총 약 60분)으로 다시 짠 판이다. 한 회는 훅 하나와 엔딩 훅 하나로 이루어진다. 2화부터는 매회 전기수 강수가 지난 회를 12초로 요약하는 '지난 대목'으로 연다. 이 드라마의 시그니처다. 지난 대목이 끝나면 10초 안에 사건이 터지고, 마지막 10초는 다음 회를 누르게 만드는 대사나 그림으로 끊는다.

표기

- 씬 제목 앞의 [00:00–00:20]은 그 씬이 차지하는 대략의 타임코드다. 스토리보드는 이 구간을 기준으로 샷을 나눈다.
- (N, 강수)는 내레이션(내레이션은 처음부터 끝까지 강수 한 사람이 맡는다), (O.S.)는 화면 밖 목소리, (V.O.)는 보이지 않는 목소리다.
- Insert.는 글씨·소품 클로즈업, Flash.는 짧은 회상이다.
- (E)는 효과음, ♪는 음악이다.
- 괄호 속 지시는 배우의 말투와 동작이다.
