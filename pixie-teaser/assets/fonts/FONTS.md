# Fonts

All bundled fonts are under the SIL Open Font License 1.1 (free to use and embed in video):
Pretendard (Kil Hyung-jin), Bodoni Moda, Cormorant Garamond, Jost, Tenor Sans, Italiana, Cinzel,
Playfair Display, Montserrat, JetBrains Mono (sourced from the `pretendard` and `@fontsource/*` npm packages).

Commercial fonts (e.g. Sandoll Cloud subscription fonts) go in `licensed/` (git-ignored):
`licensed/kr.otf` (captions), `licensed/kr_title.otf`, `licensed/label.otf`.
