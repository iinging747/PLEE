# PIXIE 티저 v4 (1:04): 후시녹음 대본 (VO)

화면 자막과 같은 문장입니다. 한국어 메인과 영어 서브의 이중 언어로 되어 있습니다.
녹음 파일을 `vo/vo01.wav` … `vo/vo07.wav` 로 넣고 `python make.py audio && python make.py video`를 실행하면, 각 줄이 정해진 타이밍에 자동으로 배치되고 BGM이 -7dB 내려갑니다.

## 톤
- **낮고 가까운 목소리.** 마이크와 10~15cm 거리, 숨이 살짝 섞이게. 속삭임과 대화 사이.
- **냉철하게 시작해서 점점 부드럽게.** 앞부분은 감정을 빼고 짧게 끊고, 뷰티 구간은 따뜻하게, 여행 구간은 장난스럽게.
- **문장 끝은 딱 닫기.** 컷이 빠르기 때문에 끝을 흐리면 리듬이 무너집니다.

## 녹음 사양
WAV · 48kHz · 24bit · 모노 OK. 조용한 방에서 팝필터를 쓰고, 줄마다 3테이크씩, 앞뒤로 0.5초 무음.
