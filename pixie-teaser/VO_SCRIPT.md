# PIXIE 티저 후시녹음 대본 (1:04)

기획 흐름 그대로 갑니다. 처음엔 냉철한 트레이더, 중간엔 전혀 다른 모습, 끝엔 더 큰 세계, 마지막에 이름이랑 첫 라이브.
톤은 차갑고 짧게, 자신감 있게. 반말 독백이에요. 꾸며서 읽지 말고, 혼잣말하듯 낮게.

녹음은 조용한 방에서 폰으로 해도 괜찮아요. 입에서 10~15cm 거리에, 줄마다 2~3번씩, 앞뒤로 숨 한 번 쉴 만큼 비워 주세요.
파일 이름은 vo01~vo06. 보내주시면 타이밍 맞춰 넣고 자막도 그대로 맞춥니다.
