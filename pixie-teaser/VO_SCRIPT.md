# PIXIE 티저: 후시녹음 대본 (VO)

화면 자막과 같은 문장입니다. 한국어 메인과 영어 서브의 이중 언어로 되어 있습니다.
녹음 파일을 `vo/vo01.wav` … `vo/vo11.wav` 로 넣고 `python make.py audio && python make.py video`를 실행하면, 각 줄이 정해진 타이밍에 자동으로 배치되고 BGM이 -7dB 내려갑니다.

## 톤
- **낮고 가까운 목소리.** 마이크와 10~15cm 거리에서 숨이 살짝 섞이게 말합니다. 소리 지르지 않고 속삭임과 대화의 중간 정도.
- **냉철하게 시작해서 점점 부드럽게.** 0:30까지는 감정을 빼고 짧게 끊습니다. 1:00 이후는 미소가 들리게, 1:19는 장난스럽게.
- **문장 끝을 흐리지 않기.** 마침표에서 딱 닫아야 컷 리듬과 맞습니다.

## 녹음 사양
WAV · 48kHz · 24bit · 모노 OK. 조용한 방(옷장, 이불 아래도 OK)에서 녹음하고, 입과 마이크 사이에 팝필터를 둡니다.
줄마다 3테이크씩, 앞뒤로 0.5초 무음을 남겨 주세요. 파일명은 아래 ID를 따릅니다.

## 대체 문장 (톤을 바꾸고 싶을 때)
- vo01: "시장은 감정을 먼저 시험하죠." (구어체)
- vo04: "빠르게 판단하고, 조용히 기다린다."
- vo07: "차트를 덮으면, 나는 조금 더 부드러워져요."
- vo09: "트레이더라고만 생각했죠?"
- vo11: "곧, 라이브에서." / "See you soon, live."

문장을 바꾸면 `timeline.py`의 `VO` 목록과 `caption(...)` 문구도 같이 수정하면 자막이 맞춰집니다.
